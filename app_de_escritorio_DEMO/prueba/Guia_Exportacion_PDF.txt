# 📄 GUÍA DE EXPORTACIÓN A PDF

## Sistema SCORE2 - Reportes de Pacientes

---

## 🎯 ¿QUÉ ES ESTA FUNCIÓN?

Permite al doctor **exportar un reporte completo en PDF** de cualquier paciente, incluyendo:

✅ Datos personales del paciente  
✅ Historial completo de evaluaciones de riesgo  
✅ Interpretación médica del último cálculo  
✅ Recomendaciones específicas según categoría de riesgo  
✅ Formato profesional listo para imprimir o enviar  

---

## 🚀 CÓMO USAR

### Paso 1: Instalar reportlab (si aún no lo hiciste)

```bash
pip install reportlab
```

### Paso 2: En la aplicación

1. **Abre la pestaña "👥 Pacientes"**
2. **Selecciona el paciente** que quieres exportar (un click en la fila)
3. **Presiona el botón "📄 Exportar PDF"**
4. **Elige dónde guardar el archivo**
   - Nombre sugerido: `Reporte_Apellido_Nombre_YYYYMMDD.pdf`
5. **¡Listo!** El PDF se genera automáticamente

REPORTE DE RIESGO CARDIOVASCULAR

### 2. **DATOS DEL PACIENTE**

- Fecha de nacimiento
- Sexo

- Email

### 3. **HISTORIAL DE EVALUACIONES**

Tabla completa con todas las evaluaciones realizadas:

| Fecha | Edad | Fumador | PAS | Col no-HDL | Riesgo % | Categoría | Método | Región |
|-------|------|---------|-----|------------|----------|-----------|--------|--------|
| 22/01/2026 14:25 | 51 | Sí | 130 | 4.8 | 8% | Moderado | SCORE2 | MODERADO |
| 15/12/2025 10:15 | 51 | Sí | 135 | 5.2 | 11% | Moderado | SCORE2 | MODERADO |

**Características:**
- ✅ Colores según categoría (Verde=Bajo, Naranja=Moderado, Rojo=Alto)
- ✅ Filas alternadas para mejor lectura
- ✅ Ordenado por fecha (más reciente primero)

### 4. **ÚLTIMA EVALUACIÓN - INTERPRETACIÓN**

**Texto automático según categoría:**

#### Si es RIESGO BAJO:
> "El paciente presenta un riesgo BAJO (3%) de sufrir un evento cardiovascular 
> mortal o no mortal en los próximos 10 años. Este nivel de riesgo es favorable 
> y sugiere que el paciente mantiene buenos hábitos de vida..."

#### Si es RIESGO MODERADO:
> "El paciente presenta un riesgo MODERADO (8%) de sufrir un evento cardiovascular 
> en los próximos 10 años. Este nivel de riesgo indica la necesidad de intervención 
> preventiva. Se recomienda modificación intensiva del estilo de vida..."

#### Si es RIESGO ALTO:
> "El paciente presenta un riesgo ALTO (23%) de sufrir un evento cardiovascular 
> en los próximos 10 años. Este nivel de riesgo requiere intervención inmediata 
> y agresiva. Se recomienda tratamiento farmacológico intensivo..."

### 5. **RECOMENDACIONES ESPECÍFICAS**

**Se adaptan automáticamente según:**
- Categoría de riesgo
- Si es fumador
- Necesidad de medicación

**Ejemplo para RIESGO MODERADO + FUMADOR:**
- • **CESACIÓN TABÁQUICA URGENTE:** Se recomienda derivación a programa...
- • Control de presión arterial objetivo <130/80 mmHg
- • Objetivo LDL-C <100 mg/dL (considerar estatinas)
- • Dieta estricta tipo mediterránea
- • Actividad física supervisada 5 días/semana
- • Seguimiento trimestral

## 💡 CASOS DE USO

### Caso 1: Paciente con seguimiento

**Doctor Pérez tiene un paciente con 5 evaluaciones de riesgo:**

1. Selecciona al paciente en la lista
2. Exporta a PDF
3. **Resultado:** PDF con tabla mostrando evolución del riesgo a lo largo del tiempo
4. Puede ver si el tratamiento está funcionando
5. Puede enviar el reporte al paciente por email

### Caso 2: Derivación a especialista

**Doctor García necesita derivar a un paciente a cardiología:**

1. Exporta el PDF del paciente
2. El PDF incluye todo el historial de evaluaciones
3. Adjunta el PDF en la derivación
4. El cardiólogo tiene toda la información de un vistazo

### Caso 3: Auditoría de obra social

**Obra social pide documentación de evaluaciones:**

1. Doctor selecciona los pacientes relevantes
2. Exporta cada uno a PDF
3. Envía los PDFs como respaldo
4. Documentación profesional y completa

## ⚠️ SOLUCIÓN DE PROBLEMAS

### Error: "La librería 'reportlab' no está instalada"

**Solución:**
```bash
pip install reportlab
```

Si sigue sin funcionar:
```bash
pip install --upgrade pip
pip install reportlab --no-cache-dir
```

### Error al generar el PDF

**Verificar:**
1. ✅ Que el paciente tenga datos completos
2. ✅ Que haya permisos de escritura en la carpeta destino
3. ✅ Que no haya otro PDF abierto con el mismo nombre

### El PDF se genera pero está en blanco

**Posibles causas:**
- Paciente sin evaluaciones de riesgo
- Error en la base de datos

**Solución:** Ver consola (ventana negra) para más detalles del error

## 🔧 PERSONALIZACIÓN

### ¿Quieres cambiar el encabezado?

En `main.py`, busca la función `exportar_paciente_pdf()`:

```python
# Cambiar el título
story.append(Paragraph("TU TÍTULO AQUÍ", titulo_style))

# Cambiar el subtítulo
story.append(Paragraph("Tu institución aquí", styles['Normal']))
```

### ¿Quieres agregar el logo de la institución?

```python
from reportlab.platypus import Image

# Agregar después del encabezado
logo = Image('ruta/a/tu/logo.png', width=2*inch, height=1*inch)
story.append(logo)
```

## 💬 PREGUNTAS FRECUENTES

### ¿Puedo exportar varios pacientes a la vez?

Actualmente no, pero es una mejora futura planeada. Por ahora:
- Selecciona un paciente
- Exporta su PDF
- Repite para cada paciente que necesites

### ¿El PDF incluye datos sensibles?

Sí, incluye:
- Datos personales completos
- Historial médico de evaluaciones
- DNI y datos de contacto

**Recomendación:** Manejar con confidencialidad según normativa de protección de datos.

### ¿Puedo modificar el PDF después de generarlo?

El PDF generado es estándar. Puedes:
- Abrirlo con Adobe Acrobat u otro editor de PDF
- Agregar anotaciones
- Firmar digitalmente
- No se recomienda modificar el contenido generado automáticamente

### ¿Qué pasa si el paciente no tiene evaluaciones?

El PDF se genera igual con:
- Datos personales completos
- Mensaje: "No se han registrado evaluaciones de riesgo para este paciente"
- Sin sección de interpretación ni recomendaciones
